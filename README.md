# PassDelivery — web

Минимальный клиент для Pass Core API (auth, профиль, адреса). Без сборки и зависимостей.

## Запуск

ES-модули не работают с `file://`, нужен любой статический сервер:

```bash
cd passdelivery-frontend
python3 serve.py   # http://localhost:5173, без кэша браузера
```

Откройте http://localhost:5173. Адрес бэкенда по умолчанию — `http://localhost:5050`
(меняется в `js/config.js`). На бэке должен быть включён CORS
для origin фронтенда (`Authorization`, `Content-Type`, методы `PATCH`, `DELETE`).

## Структура

- `index.html` — разметка
- `css/styles.css` — стили (дизайн-токены сверху, экран входа по макету Figma, node 36:550)
- `img/login.jpg` — фото для левой части экрана входа (положить вручную, см. ниже)
- `js/config.js` — адрес бэкенда
- `js/api.js` — сессия и все ручки (`Api.*`)
- `js/ui.js` — общие хелперы интерфейса
- `js/app.js` — вход, профиль покупателя, роутинг по роли
- `js/owner.js` — кабинет владельца ресторана (`#/owner/...`)
- `js/catalog.js` — каталог ресторанов и меню для покупателя (`#/restaurants`, `#/restaurants/{id}`)
- `js/cart.js` — корзина покупателя (`#/cart`), кнопки «В корзину» в меню
- `js/orders.js` — оформление (`#/checkout`), заказ и его статус (`#/orders/{id}`), история в профиле
- `js/courier.js` — кабинет курьера (`#/courier`): линия, предложения, текущая доставка
- `js/reviews.js` — отзывы: рейтинг и список (ресторан, кабинет), форма на странице доставленного заказа
- `js/notifications.js` — колокольчик уведомлений (покупатель, владелец, курьер)
- `serve.py` — dev-сервер фронта без кэша браузера


## Фото для экрана входа

Файл `img/login.jpg` не входит в репозиторий автоматически. Пока его нет, слева показывается тёплый градиент.
В Figma выдели слой с фото (Rectangle в фрейме Login screen) → справа в панели Export выбери JPG, 2x → Export → сохрани как `img/login.jpg`.
